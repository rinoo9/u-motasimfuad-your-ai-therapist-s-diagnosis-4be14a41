Entry for the make.fun bounty "Your AI Therapist's Diagnosis" — the funniest single-line diagnosis an AI therapist hands its human, 200 characters or less. The program writes the diagnosis to `/output/entry.txt`.

> "Diagnosis: your childhood was fine. The trauma is your inbox: 4,000 unread emails, each one personally disappointed in you."

Character count: 123.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt`. Deterministic: the same line on every run, no input, no randomness, no network.
